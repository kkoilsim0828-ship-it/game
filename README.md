# 영어 단어 산성비 · 1,800

영단어·표현을 입력해 떨어지는 글자를 없애는 한국어 사용자를 위한 영어 학습 게임입니다.

## 실행

1. `index.html`을 내려받습니다. GitHub 파일 화면의 **Download raw file**을 이용하세요.
2. 파일을 Chrome 또는 Edge 등 브라우저로 엽니다.
3. 분류·난이도·낙하 속도를 고르고 **게임 시작**을 누릅니다.
4. 화면의 영어를 입력하고 Enter를 누릅니다. 표현은 띄어쓰기를 포함해 입력합니다. 대소문자와 연속 공백 차이는 허용합니다.

단어 데이터는 HTML 안에 포함되어 별도 서버나 설치 없이 실행됩니다. GitHub의 코드 보기 화면은 게임 실행 화면이 아닙니다.

## 기본 수록 · 중복 없이 총 1,800개

| 분류 | 개수 | 예시 |
|---|---:|---|
| 일상 영어 | 900 | hello, family, breakfast, weather |
| 직장·일반 업무 | 400 | meeting, invoice, deadline, purchase order |
| 설비·전기·로봇·보전 | 300 | interlock, programmable logic controller, bolster, preventive maintenance |
| 자주 쓰는 숙어·표현 | 200 | look forward to, give me a hand, as soon as possible |
| 합계 | **1,800** | 기존 93개 모두 포함 |

분류에는 한 단어뿐 아니라 복합명사·구동사·일상 문장도 포함됩니다. 동사 활용형 등은 별도 표제어로 셉니다. 한국어 뜻은 학습용 대표 뜻이며 모든 뜻·문법 용법을 망라하지 않습니다. 네이버 사전 본문을 대량 복사한 자료가 아니며, 한국어 설명을 직접 정리한 학습용 목록입니다.

## 기능

- 게임 난이도: 쉬움·보통·어려움. 생명·단어 생성 간격·낙하 속도에 차이를 둡니다.
- 낙하 속도: ×0.6·×1·×1.5. 진행 중에도 변경할 수 있습니다.
- 분류 선택: 기본 4분류·기본 전체와 내 단어·내 단어·복습.
- 길이 선택: 6자 이하·7~10자·11자 이상. 공백·하이픈·아포스트로피를 제외한 철자 수 기준이며 공인 학습 등급이 아닙니다.
- 단어장: 1,800개 전체를 영어·한국어로 검색하고 분류별로 찾아볼 수 있습니다. 한 페이지에 30개씩 표시하고 발음을 들을 수 있습니다.
- 내 단어: 한 줄에 `영어 | 한국어 뜻 | 한글 발음(선택)` 형식으로 추가합니다. 영어는 32자 이내이며 기존 사용자 단어는 수정할 수 있습니다.
- 복습: 오답 입력 시 가장 아래쪽 단어, 바닥에 닿은 단어를 기록합니다. 복습 시작은 현재 게임을 초기화합니다.
- 일시정지·계속하기, 다른 탭으로 이동 시 자동 일시정지.
- 정답 자동 발음 선택, 마지막 단어 발음 다시 듣기.
- 최고 점수·사용자 단어·복습 기록을 브라우저 localStorage에 저장합니다. 이전 93개 버전과 같은 저장 키를 사용합니다.

오답 입력만으로 의도한 단어를 확정할 수 없으므로 가장 아래쪽 단어를 복습 대상으로 선택합니다. 기본 전체 모음에서 사용자 단어와 철자가 같으면 사용자 뜻을 우선합니다.

## 저장·발음

기록은 기기·브라우저별이며 자동 동기화되지 않습니다. 브라우저 데이터 삭제, 파일 위치나 브라우저 변경에 따라 이전 기록이 보이지 않을 수 있습니다. 저장이 제한된 환경에서는 현재 실행 동안만 기록을 유지합니다.

음성은 브라우저 Web Speech API를 사용합니다. 사용 가능한 영어·한국어 음성과 오프라인 재생 여부는 브라우저·운영체제에 따라 달라집니다. 새 단어에는 임의의 한글 발음 표기를 추가하지 않았으며 영어 음성으로 재생합니다.

## 파일과 검증

- `index.html`: 게임과 기본 단어 데이터가 포함된 단일 실행 파일.
- `data/vocabulary.json`: 편집·재사용을 위한 같은 1,800개 원본 목록. 변경 시 HTML의 `VOCABULARY`도 함께 갱신해야 합니다.
- 구성 항목: `en`, `ko`, `pron`, `category`. `category`는 `daily`, `business`, `work`, `phrases`입니다.

확인: 기본 데이터 1,800개·철자 중복 없음·분류별 정확한 개수·기존 93개 유지·HTML과 JSON 일치. DOM 모의 환경에서 입력, 점수, 복습, 일시정지, 저장, 검색, 길이 필터 등 24개 로직 검사를 통과했습니다. 실제 브라우저 화면·음성 재생은 별도 확인이 필요합니다.

사용자가 제공한 HTML 게임을 기반으로 ChatGPT가 기능과 단어장을 확장했습니다. 현장 단어의 한국어 설명은 영어 학습용이며 설비 조작 지침이 아닙니다.
