# 영어 단어 산성비 게임

`index.html`을 내려받아 Chrome 또는 Edge로 열고 게임 시작을 누르세요. 별도 설치나 서버가 필요하지 않습니다. GitHub 파일 화면에서는 게임이 직접 실행되지 않습니다.

## 기능
- 쉬움·보통·어려움과 별도 낙하 속도 선택
- 일상 영어, 현장 업무 영어 34개, 내 단어, 전체, 복습 모음
- `영어 | 한국어 뜻 | 한글 발음(선택)` 형식의 단어 일괄 추가
- 오답 및 놓친 단어 자동 기록과 복습 게임·발음 듣기
- 최고 점수·내 단어·복습 기록을 브라우저 localStorage에 저장
- 일시정지·계속하기, 다른 탭으로 이동 시 자동 일시정지
- 정답 자동 발음 선택 및 마지막 단어 다시 듣기

오답은 입력 대상이 확정되지 않으므로 가장 아래쪽 단어를 복습 대상으로 기록합니다. 복습 게임 시작은 현재 게임을 초기화합니다. 난이도와 모음은 시작 전에, 낙하 속도는 게임 중에도 바꿀 수 있습니다.

저장 기록은 브라우저·기기별이며 자동 동기화되지 않습니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 발음은 브라우저 음성 기능과 설치된 언어 음성에 따라 달라집니다.

## 출처
